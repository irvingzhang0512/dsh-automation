# Irving · 自动化增强

为 DSH 内置自动化增加命令与脚本任务，支持定时执行、失败重试、超时和并发控制，并查看运行记录与输出。

## 能做什么

- 定时执行本机命令或 Python、Bash、PowerShell、JavaScript 脚本，不创建会话或调用模型。
- 设置一次性、每日、每周、每月、Cron 等触发规则，为任务指定时区。
- 在任务重叠时选择跳过、排队或并行，设置超时和失败重试。
- 手动立即运行、取消某次运行，查看历史、标准输出、错误输出和退出码。

官方会话任务仍由 DSH 内置自动化处理，适合需要模型或 Skill 的总结、分析等任务。本插件与官方任务共用「自动化任务」入口。

## 安装

当前本地版本 **0.2.1-rc.2+rev.1**，要求 **DSH Desktop 0.2.1-rc.2**。自动化已由宿主内置提供，无需安装旧实验性 Schedule Bundle；本插件核对宿主内置自动化的实际版本。运行脚本还需要本机安装对应解释器。

截至 2026-10-18，[公开源码仓库](https://github.com/irvingzhang0512/dsh-automation)默认分支包版本为 **0.2.2**，属于旧实现，不能根据数字大小认作本页版本。当前 Desktop 适配版尚未公开推送或发布；先向维护者获取对应版本的完整预构建 `.tgz`。

1. 打开「插件 → 添加插件 → 安装第三方插件」，填写安装包的本机绝对路径。
2. 核对包名 `dsh-automation` 和完整版本，启用后按提示重启 DSH。
3. 打开左侧「自动化任务」，确认能在同页切换「会话任务／直接任务」。

构建与目标环境验证见 [本版兼容记录](docs/DSH-UPGRADE-20261017.md)。本页不提供尚未发布的 tag 或 npm 安装命令。

## 配置

进入「插件 → Irving · 自动化增强」查看「官方配置」「Automation 配置」。各分区按所属服务分别保存，没有统一的保存全部操作。

| 常用设置 | 默认值 | 首次使用建议 |
|---|---|---|
| 直接任务超时 | 1800 秒 | 沿用默认，或在任务中单独设置 |
| 调度检查间隔 | 1000 毫秒 | 沿用默认 |
| 数据目录 | DSH 数据目录下的 `automation/` | 已有任务时保持原目录，修改此项不会搬迁数据 |
| 常规数据库备份 | 保留 10 份 | 沿用默认 |

任务级的解释器、参数、工作目录、环境变量、时区、重叠策略和重试均在任务表单填写。参数每行一个，环境变量每行 `NAME=值`。完整默认值、保存与生效时间见 [配置指南](docs/CONFIG-UI.md)。会导致直接执行服务重载的保存需要先结束运行中任务。

## 第一次使用

用一次无业务文件写入的命令检查直接任务：

1. 先在本机终端确认 `node --version` 可以运行，记下可用的 Node 程序名或绝对路径。
2. 进入「自动化任务 → 直接任务 → 新建直接任务」，选择命令，名称填写「查看 Node 版本」，程序填写刚确认的 Node，参数填写一行 `--version`。触发时间设为未来一次，核对时区后保存。
3. 点击「立即运行」，在历史中打开本次记录。状态应成功，输出为 Node 版本，退出码为 `0`。
4. 删除这项示例任务，或取消尚未触发的计划，避免之后再次运行。

新建按钮只打开表单；保存按计划执行，「立即运行」才主动执行一次。

## 常用操作

| 想做什么 | 怎么做 | 结果 |
|---|---|---|
| 定时运行脚本 | 先保存脚本，再填写实际路径、解释器和计划 | 到时间在本机执行该文件 |
| 查看失败原因 | 打开历史中的失败记录 | 查看错误输出、退出码及重试情况 |
| 停止长任务 | 取消指定的本次运行 | 不删除任务，也不取消后续周期 |
| 创建需要模型的任务 | 切到会话任务，通过官方入口创建 | 到时由官方自动化在会话中处理 |

## 使用边界

- DSH 和执行环境需要保持运行。宿主关闭时不调度，重启不会补跑错过的周期；中断运行标记为结果未知，不自动重跑。
- Windows 的 Bash 脚本需要可用 Bash，PowerShell 默认使用 `pwsh`；解释器可填写完整路径。
- 脚本以 DSH 进程的实际权限运行，业务结果由脚本决定。
- 旧模型任务迁移需要预览、选择会话、处理不等价规则并备份，详见配置指南。修改目录不会自动迁移数据库。
- 当前模型工具使用 `automation_` 前缀。历史点号工具名已退役，旧会话报旧名称时先在新会话核对实际工具。

## 常见问题

### 为什么实验性插件里没有官方自动化

当前 DSH 已将它内置。直接从左侧「自动化任务」进入，本插件配置在自研插件详情中。

### 保存后没有立即运行

先看下次触发时间和时区。要主动执行一次，请点击「立即运行」，随后在历史查看实际结果。

### 脚本提示找不到程序

在运行 DSH 的机器确认解释器可用，必要时填写完整路径，并检查工作目录和脚本路径。修改后核对一次新运行的输出。
