# 自动化任务同页整合契约

批准版 `automation-integrated-page-20261014-v2`；用户于 2026-10-14 明确要求实施本计划。目标版本 `0.2.0-rc.2+automation.2`，官方基线保持 `0.2.0-rc.2`。原实施契约的执行、配置、API 与持久层语义不变，本契约更新 F007／F012，并新增 F016。

## 页面行为

现有侧栏“自动化任务”唯一入口进入 `main` 的 `schedules` 页面。顶部常驻“会话任务／直接任务”切换与“新建直接任务”按钮，默认会话任务。官方“新建”继续创建会话；新建直接任务切到直接页并打开命令／脚本表单，不立即执行或创建 Session。直接任务保留任务／待运行／运行中／历史四标签；两类数据不合并。

常驻说明：会话任务到时间后让模型在原会话处理指令，可用 Skill，适合总结分析；直接任务到时间后运行本机命令或五种脚本，不创建会话／调用模型，适合确定性工作。两类均需 DSH 保持运行，直接执行不等于立即执行；脚本先保存为本地文件。

两页首次访问后保持挂载，隐藏当前未选的一页，切换保留筛选／选择／滚动。直接创建／编辑表单有未保存修改时，离开或再次新建先确认放弃，取消保留表单；保存中拒绝离开，成功保存／确认放弃后解除保护。表单只读查看无需确认。插件详情旧按钮打开同页直接任务，旧 `automation` 面板作为兼容入口重定向。

嵌入表单遮罩仅覆盖直接任务内容区，顶部类型切换与新建按钮保持鼠标可达，切换保护从真实点击触发；独立模式仍使用整页遮罩。

## 客户端接缝

通过公开 `slots.entries/subscribe/register` 读取 `main` 中官方 `key=schedules`、`locale=schedule.manager` 的原注册，采用独立优先级注册组合页。复制官方公开 `inject`／`locale`，将框架完成绑定后的 props 原样交给其原 Component；不调用组件函数，不重新实现官方目录／修改接口，不停用官方成员、不修改安装包或官方 DOM。

官方注册迟到／重载时重建组合注册；不存在或不唯一时不覆盖官方页面。增强卸载时移除自有注册、导航状态与监听，恢复原官方优先级项。客户端声明官方 UI 模块加载依赖，避免加载顺序猜测。

导航状态仅存在当前客户端内存：任务类别与新建请求计数，不写配置／数据库。AutomationPage 增加嵌入模式、新建请求和离开保护注册能力；新建请求只打开任务表单，不能触发 API 写入。隐藏面板用 `hidden` 和自有样式，不移除原组件状态。
