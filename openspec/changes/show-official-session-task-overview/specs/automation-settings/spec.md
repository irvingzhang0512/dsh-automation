# Spec Delta

## ADDED Requirements

### Requirement: 官方配置显示会话任务概览

插件 SHALL 在「官方配置」顶部提供只读的「会话任务」概览。概览使用当前 DSH 连接中官方 Schedule 接口授权的任务清单。每行显示任务名、排程状态、下次投递与最近投递。默认视图包含已排程或有执行信号的任务，「全部」视图额外包含暂停和已结束任务。每次加载和刷新 SHALL 保留现有设置草稿。

#### Scenario: 默认视图与全部任务

- **WHEN** 官方清单含已排程、暂停与已结束任务，也含暂停后仍有执行信号的任务
- **THEN** 默认显示已排程及所有有执行信号的任务，「全部」显示整个官方清单。仅已排程任务显示下次投递。缺失时间显示「—」。

#### Scenario: 区分排程、投递和执行

- **WHEN** 官方清单报告任务有执行信号或含最近投递时间
- **THEN** 执行信号显示为「排队或执行中」，最近投递时间单独显示。每次创建新会话且缺少执行信号时，执行状态为「未知」。投递回执只表示会话收到任务。

#### Scenario: 初次加载和后续刷新

- **WHEN** 打开官方配置区、官方任务变化、连接恢复或用户点击刷新
- **THEN** 使用当前连接重新读取官方清单。首次加载、成功后的空结果、访问受限和读取失败分别显示。当前连接上的刷新失败时保留最近成功结果并标明可能过时，权限撤销或连接重置时清除旧数据。

#### Scenario: 导航至官方任务

- **WHEN** 用户从官方配置选择「打开会话任务」
- **THEN** 进入现有「自动化任务」侧栏页并选中「会话任务」。在该页访问官方详情、投递记录、会话链接和管理操作。现有「直接任务」入口及离开直接任务的草稿保护继续适用。
