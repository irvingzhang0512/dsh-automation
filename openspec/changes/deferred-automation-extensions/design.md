# 候选设计与未决项

## Context

历史原文只读保留，当前实现契约见本库 openspec/specs 与 MIGRATION.md。本文件不把候选接口、配置键或命令描述为已经可运行。

## Goals / Non-Goals

目标是保留历史需求并建立后续细化、确认、实现和验证入口；本轮不开发业务、不改数据、不安装、不运行任务。

## Decisions

- command/script为现有直接执行；skill/agent_prompt改由官方原对话，不恢复旧Agent名称创建Session。
- 事件/条件需定义判定时机、来源、去重、重放、权限与循环抑制。
- Plugin Action/Workflow/Tool Action仅候选，公开接口尚待验证。
- 今晚不跑/明天改时间不同于取消已有run_id；需定义未物化occurrence身份、例外记录与周期保持。
- 通知成功/失败/超时/长耗时阈值、收件范围与失败策略需明确，原文不是外发授权。
- 实时日志需截断、背压、鉴权和重连，不放宽现有输出上限。
- 原dsh automation start/stop/restart/status不是当前命令；独立后台服务/自启动如需要另立确认。

## Risks / Trade-offs

历史愿望并非完整设计，不能用空缺处的默认推测替代用户确认。任何接口/配置/存储变化需列明旧值去向、失效字段清理、完整引用、备份、CAS、恢复与回滚；不静默改已有资料。

## Migration Plan

目前无业务迁移执行计划。文档版确认后再设计实际数据迁移，先预览、验证备份和冲突，实施状态与实测证据分开记录。

## Open Questions

需选优先能力，确认触发来源/条件、插件动作、通知渠道/授权、实时订阅、未来occurrence编辑和筛选字段。独立后台服务是否继续作为未来候选待定。
