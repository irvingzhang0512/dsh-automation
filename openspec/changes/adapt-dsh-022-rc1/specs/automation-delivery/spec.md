# Spec Delta

## ADDED Requirements

### Requirement: 0.2.2 rc1 完整固定运行

插件 SHALL 在固定宿主 0.2.2-rc.1 以完整版本 0.2.2-rc.1+rev.1 交付，源码和运行资源可核验，保留原身份、接口与业务语义。

#### Scenario: 真实目标加载

- **WHEN** 目标宿主安装固定完整提交
- **THEN** 工具、Skill 及客户端按原职责加载，源码与完整产物一致，未验证服务保持待验

### Requirement: 0.2.2 rc1 领域行为保真

插件 SHALL 保持直接命令／脚本执行、明确时区及旧任务迁移恢复；适配新的官方提醒接口并明确保持原会话投递。

#### Scenario: 旧提醒目标保持

- **WHEN** 把旧提示词或 Skill 任务迁入官方日程
- **THEN** 规则、时区和原会话目标一致，不因省略目标新建会话

#### Scenario: 旧迁移记录恢复

- **WHEN** 读取 rc5 migration-records 并请求恢复
- **THEN** 规范比较新 catalog；未修改且未投递的本次提醒可删，已修改／投递及冲突均拒绝，部分失败可继续恢复

#### Scenario: 时间规则边界

- **WHEN** 迁移每小时、工作日、每周或不受支持的月末规则
- **THEN** 支持规则保持原发生时刻，旧 monthly>28 继续明确阻断

### Requirement: 配置与资料保护

插件 SHALL 区分原始覆盖和实际生效配置，保留原字段、引用、资料和凭据；取消或冲突不写入，回退不覆盖后续业务。

#### Scenario: 继承及并发编辑

- **WHEN** 设置含默认／继承／表达式值，用户取消或原配置并发变化
- **THEN** 显示实际生效值，取消无写入、冲突拒绝；保存仅修改目标原始覆盖

#### Scenario: 停用与恢复

- **WHEN** 插件被停用、卸载或升级失败
- **THEN** 业务资料和原选择保留；不通过整目录恢复覆盖后续内容
